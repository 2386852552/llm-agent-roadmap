# 学习笔记分析

## 1. 简介摘要  
Python 是一种高级编程语言，以其简洁和易读性著称。它支持多种编程范式，包括面向对象、函数式和过程式编程。在人工智能领域，Python 因其丰富的生态系统和广泛使用的库（如 NumPy、Pandas、PyTorch 和 Transformers）而被广泛应用。

## 2. 5 个关键词  
- Python  
- 高级编程语言  
- 面向对象编程  
- 人工智能  
- 库（如 NumPy、Pandas、PyTorch、Transformers）

## 3. 3 个适合复习的问题  
1. Python 有哪些主要的编程范式？  
2. 在人工智能领域，Python 的优势是什么？  
3. 列举几个常见的 Python 库，并说明它们的用途。
